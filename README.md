# Portfolio (Flutter Web)

Personal portfolio site built with Flutter Web: home, about, projects, services, blog, contact.

Older homework / experiments. Useful as Flutter Web + Provider, not as a production product.

**Live products I actually ship:** [Hazina](https://github.com/Thedarik/hazina) · [EduFlix](https://eduflix.uz) · [UzNext](https://uznext.uz)

## Stack

- Flutter Web
- Provider
- `google_fonts`, `flutter_animate`, `animated_text_kit`
- `url_launcher`, `http`, `carousel_slider`

## Run

```bash
git clone https://github.com/Thedarik/partfolio-code.git
cd partfolio-code
flutter pub get
flutter run -d chrome
```
